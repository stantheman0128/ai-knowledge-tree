## OpenAI releases Codex Security research preview to detect application vulnerabilities

OpenAI has introduced Codex Security, an AI agent designed to identify and patch security flaws in software applications. The tool aims to assist developers in securing codebases, though it arrives amidst growing concerns about the security risks posed by AI agents themselves.
