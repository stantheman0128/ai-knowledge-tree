## NVIDIA introduces 12B parameter Nemotron 3 VoiceChat model

NVIDIA launched the Nemotron 3 VoiceChat model, a 12B parameter end-to-end real-time full-duplex voice model. It is designed for developers to build voice-based agents with customizable personas.
