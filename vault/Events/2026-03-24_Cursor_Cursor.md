## Cursor introduces sparse N-grams indexing to reduce agent search latency

Cursor has implemented a new text indexing technique using 'sparse N-grams' to drastically reduce search latency in large codebases. This optimization allows AI agents to perform regex searches in milliseconds, improving the efficiency of code investigation and refactoring.
