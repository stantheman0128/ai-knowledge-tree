## NVIDIA releases Lyra 2.0 for generating explorable 3D worlds from single images

NVIDIA Research introduced Lyra 2.0, a framework that generates persistent, explorable 3D environments from a single input image. It solves spatial and temporal drift issues, allowing users to export high-quality 3D assets for use in physics engines like NVIDIA Isaac Sim.
