## Microsoft removes Copilot integration from several built-in Windows applications

Microsoft is rolling back Copilot features in Windows apps like Photos and Notepad due to user feedback describing the integration as intrusive. This retreat highlights a growing disconnect between aggressive AI deployment and actual user demand.
