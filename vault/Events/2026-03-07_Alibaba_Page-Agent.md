## Alibaba open-sources Page Agent for JavaScript-based GUI control

Alibaba has released Page Agent, a pure JavaScript GUI agent that allows developers to control Web application interfaces using natural language. It operates via DOM manipulation without requiring backend Python or browser extensions.
