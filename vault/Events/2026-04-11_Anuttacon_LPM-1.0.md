## Anuttacon unveils LPM 1.0 video performance model for academic use

Founded by miHoYo's Cai Haoyu, Anuttacon introduced LPM 1.0, a 17B parameter model for real-time video character performance. The model is currently restricted to academic research with no public API or commercial release planned.
