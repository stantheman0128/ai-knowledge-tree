## WordPress.com expands MCP support to allow AI agents to write content

WordPress.com has updated its platform to allow AI agents to directly write and manage content via MCP. Paid users can now authorize agents like Claude and ChatGPT to draft posts, build landing pages, and manage comments with human oversight.
