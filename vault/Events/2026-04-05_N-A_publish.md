## New method enables real-time steering of visual features via text prompts

By injecting cross-attention layers inside ViT encoder blocks, researchers have developed a way to steer visual representations using text prompts. This early-fusion approach preserves spatial information better than traditional methods, improving performance in anomaly detection and object discrimination.
