## AAA game engines utilized as high-quality data source for generative rendering

Researchers extracted 4 million synchronized RGB and G-buffer frames from AAA games to create a superior dataset for inverse rendering. This method bridges the domain gap between synthetic and real-world data, enabling better cross-dataset generalization and controllable video generation.
