## Google introduces Flex and Priority inference tiers for Gemini API

Google has launched two new inference tiers, Flex and Priority, for the Gemini API to provide developers with more control over cost and latency. This update allows users to better optimize their applications by choosing the tier that best fits their performance and budget requirements.
