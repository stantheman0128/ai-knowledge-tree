## ACES framework resolves circular dependency in automated code test selection.

ACES introduces a method to weight code tests based on ranking consistency rather than correctness, bypassing the circular problem of needing correct code to verify tests. It requires no extra model calls and improves Pass@k metrics in code generation pipelines.
