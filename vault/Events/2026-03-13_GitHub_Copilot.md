## GitHub restricts model selection in Copilot student plan

GitHub has removed the ability for students to manually select advanced models like GPT-5.4 and Claude Opus in their Copilot student plan. The change aims to maintain free service access for nearly 2 million students while keeping existing quotas and verification status intact.
