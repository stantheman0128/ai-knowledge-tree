## OpenAI launches sandboxed container environment for AI agents

OpenAI has upgraded its Responses API to include a managed, sandboxed Linux container environment for AI agents. This allows developers to execute code, install dependencies, and manage persistent file systems directly within OpenAI's infrastructure.
