## Self-distillation method halves reasoning tokens and improves accuracy for Qwen3 models.

Researchers introduced a self-distillation technique that prompts models to answer concisely, using those outputs as teacher signals to refine default behavior. This approach significantly reduces reasoning token usage while simultaneously boosting performance on MATH-500 and AIME benchmarks.
