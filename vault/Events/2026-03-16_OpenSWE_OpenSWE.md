## OpenSWE releases 45,320 Dockerized training environments for SWE agents

OpenSWE has open-sourced a massive dataset of 45,320 executable Docker environments across 12,800 Python repositories to solve the infrastructure bottleneck in software engineering agent training. The project, which cost $1.47M to build, provides the necessary feedback loops for agents to iterate on code, significantly improving performance on SWE-bench and general reasoning tasks.
