## Ai2 releases open-source visual web agent MolmoWeb

Ai2 has launched MolmoWeb, an open-source visual agent capable of performing web tasks like clicking and scrolling by interpreting screenshots rather than HTML. The release includes the model weights and the MolmoWebMix dataset, setting a new benchmark for open-weight web agents.
