## Tencent Cloud launches Coding Plan AI programming subscription service

Tencent Cloud has introduced 'Coding Plan', an AI programming subscription service that integrates major models like Hunyuan, Zhipu, Kimi, and MiniMax. The service offers Lite and Pro tiers with tiered pricing, supporting integration with tools like Cursor and Cline.
