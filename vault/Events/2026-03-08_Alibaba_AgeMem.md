## Alibaba and Wuhan University introduce AgeMem memory framework

Researchers from Alibaba and Wuhan University developed AgeMem, a framework that integrates long-term and short-term memory management directly into LLM agent policies. The system uses reinforcement learning to allow agents to autonomously manage information storage and retrieval.
