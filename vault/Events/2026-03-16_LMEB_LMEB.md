## New LMEB benchmark reveals traditional metrics fail to predict memory retrieval

The Long-horizon Memory Embedding Benchmark (LMEB) evaluates 15 embedding models across 193 tasks to assess memory retrieval capabilities. The study finds that performance on traditional benchmarks like MTEB is orthogonal to memory retrieval, suggesting that current ranking systems do not accurately reflect a model's ability to handle episodic or conversational memory.
