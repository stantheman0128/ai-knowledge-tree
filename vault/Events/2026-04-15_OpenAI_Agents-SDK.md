## OpenAI updates Agents SDK with native sandbox execution

OpenAI has updated its Agents SDK to include native sandbox execution and a model-native harness for long-running processes. By integrating isolation directly into the framework, OpenAI aims to facilitate safer production deployment of autonomous agents.
