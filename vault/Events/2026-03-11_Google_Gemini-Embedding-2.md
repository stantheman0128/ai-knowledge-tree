## Google releases Gemini Embedding 2, a native multimodal embedding model.

Google has launched Gemini Embedding 2, a native multimodal model capable of mapping text, images, audio, video, and documents into a unified vector space. It is currently available in public preview via Gemini API and Vertex AI, offering state-of-the-art performance for RAG and semantic search.
