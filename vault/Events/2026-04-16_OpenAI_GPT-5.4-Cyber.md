## OpenAI launches Trusted Access for Cyber initiative with $10M in API grants

OpenAI has introduced the Trusted Access for Cyber program, partnering with leading security firms to enhance global cyber defense capabilities. The initiative provides participants with access to the GPT-5.4-Cyber model and $10M in API credits to accelerate the development of advanced security solutions.
