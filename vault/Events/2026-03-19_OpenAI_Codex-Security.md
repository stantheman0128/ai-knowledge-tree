## OpenAI updates Codex Security to replace static analysis with AI-driven reasoning

OpenAI has updated its Codex Security product to move away from traditional rule-based static analysis (SAST) in favor of AI-driven constraint reasoning. The company argues that this approach reduces false positives by assessing whether flagged patterns constitute actual exploitable vulnerabilities rather than just matching predefined rules.
