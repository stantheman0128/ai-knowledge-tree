## OpenClaw-RL enables agents to learn continuously from interaction signals.

OpenClaw-RL provides a framework that unifies dialogue, terminal, and GUI feedback into a single reinforcement learning loop. The system allows agents to learn while serving by using posterior distillation for token-level corrective supervision.
