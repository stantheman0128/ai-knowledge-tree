## InCoder-32B-Thinking released as an open-source model for hardware code debugging.

InCoder-32B-Thinking uses error-driven chain-of-thought reasoning to assist in hardware design and GPU kernel optimization. It achieves top-tier performance on benchmarks like LiveCodeBench and CAD-Coder, providing a specialized tool for hardware engineers.
