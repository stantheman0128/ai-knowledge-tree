## VISOR improves VLM efficiency by replacing dense attention with sparse, on-demand querying.

VISOR optimizes Vision-Language Models by using a dynamic policy network to query visual tokens only when necessary, rather than compressing them. This method reduces compute costs while maintaining high-resolution visual information and improving performance on complex tasks.
