## CanaryRAG introduces runtime adversarial games for RAG security

CanaryRAG shifts RAG defense from static filtering to a runtime integrity game using canary tokens embedded in document chunks. This plug-and-play method enables real-time detection of extraction attacks without requiring model retraining.
