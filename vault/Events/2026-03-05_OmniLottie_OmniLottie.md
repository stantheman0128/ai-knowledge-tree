## OmniLottie enables AI to generate editable vector animation files directly.

OmniLottie introduces a tokenizer that compresses Lottie JSON into structured sequences, allowing vision-language models to generate production-ready vector animations. The project includes a 2-million animation dataset and has been accepted at CVPR.
