## MoDA introduces cross-layer attention to improve deep model performance.

MoDA (Mixture-of-Depths Attention) allows attention heads to access KV pairs from preceding layers, mitigating signal degradation in deep LLMs. The architecture achieves significant downstream task improvements with minimal FLOPs overhead and has been fully open-sourced.
