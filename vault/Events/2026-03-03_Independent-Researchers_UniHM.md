## UniHM enables dexterous hand manipulation via natural language

UniHM is a new model that uses VLMs to interpret language instructions for dexterous robotic hands, eliminating the need for per-object programming. By using a unified tokenizer for different hand morphologies and training on human-object interaction videos, it avoids the need for expensive teleoperation data.
