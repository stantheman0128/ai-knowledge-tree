## Linux kernel maintainers establish official AI-assisted coding policy

The Linux kernel project introduced a new policy requiring human sign-off for all code contributions, explicitly barring AI agents from certifying the Developer Certificate of Origin. Contributors must now use an 'Assisted-by' tag to disclose the use of AI tools in their development process.
