## GPT-5.3-Codex generates decompositions for even-case Hamiltonian cycles

OpenAI's GPT-5.3-Codex was utilized to generate code producing decompositions for even-case Hamiltonian cycles, a problem that remains open in formal mathematics. The model successfully tested these decompositions up to m=2000, providing empirical data for a graph with 8 billion vertices. This highlights the model's utility in exploring complex combinatorial structures.
