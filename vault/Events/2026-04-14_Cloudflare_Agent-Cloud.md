## Cloudflare launches enterprise agent platform in partnership with OpenAI

Cloudflare has introduced 'Agent Cloud', an orchestration layer that integrates OpenAI's models to manage security and scaling for enterprise agents. The platform allows businesses to deploy AI agents while maintaining compliance and the flexibility to swap underlying models.
