## CodeTracer tool released to improve agent observability and debugging

CodeTracer provides a new observability solution for AI agents, allowing engineers to track state transitions across complex, multi-stage workflows. The tool aims to solve the problem of opaque agent execution, making it easier to debug error chains in production.
