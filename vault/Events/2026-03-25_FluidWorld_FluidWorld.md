## FluidWorld replaces self-attention with PDEs for more stable world model predictions.

FluidWorld introduces a world model architecture that swaps self-attention for reaction-diffusion partial differential equations. This change provides linear complexity and superior spatial structure preservation, leading to more stable multi-step predictions compared to Transformers.
