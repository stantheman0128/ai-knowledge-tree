## ByteDance releases Seed1.8, an agent-native foundation model.

Seed1.8 integrates search, code execution, and GUI interaction directly into the foundation layer rather than relying on external frameworks. The model is optimized for production latency and cost, though it lacks direct comparisons to general-purpose model setups.
