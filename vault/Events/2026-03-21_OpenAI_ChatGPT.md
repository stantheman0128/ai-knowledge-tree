## OpenAI consolidates ChatGPT, Codex, and Atlas browser into a single desktop application

OpenAI is merging its chat, coding, and browser tools into one persistent desktop application. This strategy aims to increase user lock-in and provide a unified surface for their upcoming automated AI researcher agent.
