## NVIDIA open-sources Nemotron-Cascade 2, a 3B active parameter model achieving olympiad-level reasoning.

NVIDIA released the weights and training data for Nemotron-Cascade 2, which uses a cascade reinforcement learning approach to achieve gold-medal performance on IMO, IOI, and ICPC. By utilizing multi-domain on-policy distillation, the model maintains high performance across reasoning and coding tasks without the typical regression seen in RL training.
