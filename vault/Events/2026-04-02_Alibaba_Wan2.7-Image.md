## Alibaba releases Wan2.7-Image model for interactive image editing

Alibaba's Tongyi Lab has released the Wan2.7-Image model, which unifies text-to-image generation and interactive editing. The model features advanced capabilities like virtual face customization, color palette extraction, and high-fidelity text rendering.
