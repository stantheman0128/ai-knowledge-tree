## DiT-BlockSkip reduces memory requirements for fine-tuning Diffusion Transformers.

Researchers introduced a method using dynamic patch sampling and cross-attention masks to significantly lower memory usage during DiT fine-tuning. This approach maintains high quality while enabling potential on-device deployment for personalized image generation.
