## MosaicMem uses hybrid spatial memory to improve video world model consistency.

MosaicMem combines explicit 3D reconstruction for static elements with implicit generation for dynamic evolution to solve spatial memory issues in video models. This hybrid approach enables minute-long scene navigation and better camera pose adherence compared to traditional diffusion models.
