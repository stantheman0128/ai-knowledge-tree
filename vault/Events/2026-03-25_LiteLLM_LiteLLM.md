## LiteLLM suffers supply chain attack with malicious code in two versions

The open-source AI gateway LiteLLM was compromised on PyPI, with versions 1.82.7 and 1.82.8 containing malicious code designed to steal credentials. The incident, which affected downstream projects like DSPy and CrewAI, has been mitigated by PyPI, and users are urged to downgrade and rotate their security keys.
