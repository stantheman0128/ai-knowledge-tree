## Anthropic tightens restrictions on third-party clients like OpenClaw

Anthropic has implemented stricter controls on third-party applications, specifically targeting tools like OpenClaw. The system now detects and blocks requests containing specific system prompt identifiers, requiring users to consume additional usage quotas for third-party integrations.
