## Tencent introduces HY-WU functional memory for real-time model weight adaptation

Tencent researchers unveiled HY-WU, a neural memory framework that generates instance-level weight updates in real time. This approach allows foundation models to adapt to new tasks or user preferences post-deployment without requiring expensive fine-tuning or test-time optimization.
