## BeyondSWE benchmark reveals code agents struggle with complex, multi-repo tasks.

The BeyondSWE benchmark evaluates code agents across four complex dimensions, finding that even top models fail to exceed 45% success rates. It highlights that current agents are ill-equipped for cross-repo reasoning and large-scale generation, suggesting a need for better modeling of developer workflows.
