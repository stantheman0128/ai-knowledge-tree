## Anthropic reduces Claude Code cache TTL to five minutes, sparking cost concerns

Anthropic shortened the time-to-live (TTL) for Claude Code's prompt cache from one hour to five minutes, leading to significantly higher costs for developers due to frequent re-uploads. While Anthropic describes this as an intentional optimization, users report increased expenses and quota issues during long agentic sessions.
