## Budget-Aware Value Tree search improves agent efficiency by 4x

The Budget-Aware Value Tree (BAVT) search framework optimizes LLM agent performance by dynamically adjusting exploration based on remaining token budgets. By replacing overconfident self-evaluation with relative progress scoring, it achieves superior results on multi-hop QA benchmarks at one-fourth the resource cost of brute-force sampling.
