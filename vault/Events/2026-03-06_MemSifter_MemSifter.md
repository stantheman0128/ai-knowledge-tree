## MemSifter uses a small proxy model to optimize LLM memory retrieval.

MemSifter introduces a small filtering model that selectively retrieves relevant memory for LLMs, significantly reducing context processing costs. The project is open-sourced and uses reinforcement learning to align retrieval directly with task completion.
