## OpenAI adds plugin system to Codex to expand development workflows

OpenAI has introduced a plugin system for its Codex model, allowing developers to integrate custom capabilities like linting and documentation generation. This move aims to compete with Anthropic's Claude Code by building a broader platform ecosystem directly within ChatGPT.
