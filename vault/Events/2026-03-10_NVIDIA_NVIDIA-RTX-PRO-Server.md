## NVIDIA introduces RTX PRO Server to virtualize and centralize game development workflows

NVIDIA has unveiled the RTX PRO Server, a centralized GPU infrastructure solution designed to virtualize game development pipelines. By leveraging Blackwell-based GPUs and vGPU technology, studios can consolidate creative, engineering, and AI workloads to improve hardware utilization, scalability, and security.
