## Microsoft introduces offline RL framework for agent planning in image editing

Microsoft researchers developed a framework that uses offline reinforcement learning to train vision-language models for multi-step tool-call planning. By training on synthetic trajectories with quality scoring, the model effectively automates complex image editing tasks.
