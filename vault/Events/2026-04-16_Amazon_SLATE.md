## Amazon introduces Entropy-Guided Branching for efficient agentic tool use

Amazon researchers found that plan-level search efficiency is more critical than single-step tool selection for agents. Their EGB method uses prediction entropy to allocate search budgets, improving performance in large-scale tool libraries.
