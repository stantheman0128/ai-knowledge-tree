## Anthropic releases Claude Code auto mode for autonomous permission handling

Anthropic has introduced an 'auto mode' for Claude Code, allowing the AI to autonomously manage file writes and command execution with built-in safety classifiers. This feature aims to reduce manual approval overhead while maintaining security against prompt injection.
