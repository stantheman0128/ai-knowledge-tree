## Subgoal decomposition significantly improves long-horizon web agent performance

Researchers introduced MiRA, a framework that breaks long-horizon tasks into subgoals with intermediate rewards. This approach allowed a 12B parameter model to outperform GPT-4-class systems on WebArena-Lite, demonstrating that planning is a larger bottleneck than raw model scale.
