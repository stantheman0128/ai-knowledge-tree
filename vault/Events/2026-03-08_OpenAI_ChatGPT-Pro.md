## OpenAI launches free access program for open-source maintainers

Following Anthropic's lead, OpenAI is offering six months of free ChatGPT Pro access to core open-source maintainers. The move is a strategic effort to secure adoption of OpenAI's developer tools within the broader software engineering community.
