## WildWorld dataset addresses structural flaws in world models by decoupling actions and states.

The WildWorld dataset provides 108 million frames with explicit action-state-observation decoupling to improve world model training. It highlights that current models struggle because they couple actions directly to pixels rather than learning intermediate state representations.
