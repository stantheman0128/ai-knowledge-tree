## UniGRPO provides a unified RL framework for autoregressive text and flow-matching image generation.

UniGRPO models multimodal generation as a single Markov decision process, allowing for unified post-training of hybrid architectures. By removing classifier-free guidance and using velocity-field MSE penalties, it offers a reproducible baseline for scalable multi-turn generation.
