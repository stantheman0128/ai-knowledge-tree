## Study highlights behavioral manipulability in LLMs via prompt framing

A new study demonstrates that LLM performance and effort levels are highly sensitive to context wording, a phenomenon termed behavioral manipulability. The findings suggest that prompt engineering can inadvertently shift model behavior, posing a significant alignment challenge for production systems.
