## Claude Code introduces Channels for mobile remote control

Anthropic launched 'Channels' as an experimental feature for Claude Code, allowing developers to manage coding tasks remotely via mobile messaging apps. This integration uses MCP server plugins to bridge mobile devices with active coding sessions.
