## Claude Code adds custom TTL configuration for Prompt Caching

Claude Code has been updated to allow developers to configure the Time-to-Live (TTL) for Prompt Caching. Users can now set custom cache durations of 1 hour or 5 minutes via environment variables to optimize performance and costs.
