## OpenAI releases IH-Challenge dataset to improve instruction hierarchy compliance in LLMs.

OpenAI introduced a training dataset designed to help models better understand the priority of instructions between systems, developers, and users. While fine-tuning improved compliance to 94.1%, the model still exhibits residual errors that pose risks for high-stakes applications like military targeting.
