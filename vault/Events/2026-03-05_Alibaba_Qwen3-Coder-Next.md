## Alibaba releases Qwen3-Coder-Next, an efficient 80B parameter coding agent

Alibaba has released Qwen3-Coder-Next, an 80-billion-parameter coding model that uses sparse activation to run with only 3 billion parameters at inference time. The model is open-weights and demonstrates competitive performance on standard benchmarks like SWE-bench. It aims to provide frontier-level coding capabilities with significantly reduced compute requirements.
