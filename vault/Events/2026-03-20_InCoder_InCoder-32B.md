## InCoder-32B released as a specialized foundation model for industrial code tasks.

InCoder-32B is a 32B parameter open-source model designed to bridge the performance gap in industrial code domains like chip design and GPU kernel optimization. By utilizing execution-verified post-training and progressive context extension, it outperforms general-purpose models on industrial benchmarks while maintaining competitiveness on general code tasks.
