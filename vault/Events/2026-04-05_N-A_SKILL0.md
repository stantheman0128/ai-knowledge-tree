## SKILL0 demonstrates superior agent performance through skill internalization

SKILL0 introduces a progressive withdrawal curriculum that allows agents to internalize skills directly into model parameters via reinforcement learning. This approach outperforms traditional RAG-based retrieval methods, improving performance on ALFWorld and Search-QA while reducing inference token overhead.
