## Chroma open-sources 20B parameter agentic search model Context-1

Chroma has released Context-1, a 20-billion parameter MoE model designed to act as a retrieval sub-agent. It is intended to assist frontier reasoning models by offloading search tasks to reduce overall latency and costs.
