## OpenRouter launches new 100B parameter stealth model Elephant Alpha

OpenRouter has released a new 100B parameter model called Elephant Alpha, featuring a 256K context window and 32K output limit. The model is currently free to use, though providers log all prompts and outputs for improvement purposes.
