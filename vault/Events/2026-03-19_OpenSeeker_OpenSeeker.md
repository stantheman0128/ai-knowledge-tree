## OpenSeeker releases open-source search agent trained on synthetic data.

OpenSeeker has released an open-source search agent that outperforms closed-source competitors on the BrowseComp benchmark. By using 11.7K synthetic samples and a novel data synthesis pipeline, the project demonstrates that high-performance search agents can be built without big-lab resources.
