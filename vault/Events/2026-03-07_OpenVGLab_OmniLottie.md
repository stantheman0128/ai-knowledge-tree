## OpenVGLab releases OmniLottie for multimodal animation generation

OpenVGLab has open-sourced OmniLottie, a model based on Qwen2.5-VL that converts text, image, or video inputs into compact Lottie vector animations. The release includes model weights, a large dataset, and a benchmarking suite.
