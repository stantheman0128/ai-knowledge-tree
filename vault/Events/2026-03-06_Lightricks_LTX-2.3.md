## Lightricks releases LTX-2.3 audio-video model and open-source editor.

Lightricks has launched the LTX-2.3 model, a 22B parameter DiT-based model for high-quality audio-video generation. The release includes an open-source desktop editor and supports native 1080p vertical video generation.
