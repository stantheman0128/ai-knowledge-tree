## Baidu releases 4B parameter Qianfan-OCR model

Baidu has open-sourced its 4B parameter Qianfan-OCR model, which uses a 'Layout-as-Thought' mechanism to process complex documents. The model supports 192 languages and is optimized for document intelligence tasks.
