## Cursor AI agent workflow officially launches for JetBrains IDEs

Cursor has integrated its AI agent workflow into JetBrains IDEs like IntelliJ IDEA and PyCharm via the Agent Client Protocol. This allows developers to use Cursor's features directly within their preferred Java-based development environments.
