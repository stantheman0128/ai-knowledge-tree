## RealWonder combines physics simulation with video generation for photorealistic physical interaction.

RealWonder offloads physical interaction logic to a simulation engine while using a distilled diffusion model to handle photorealistic rendering. This hybrid approach enables real-time generation at 13.2 FPS and is now available as an open-source project.
