## OpenAI releases GPT-5.4 with advanced reasoning and computer control capabilities.

OpenAI has launched GPT-5.4, a model designed for professional workflows featuring integrated reasoning, coding, and agentic computer control. It supports a 1M token context window and introduces a 'mid-generation guidance' feature for real-time user intervention.
