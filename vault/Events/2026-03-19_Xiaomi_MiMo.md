## Xiaomi releases MiMo model series with API support

Xiaomi has introduced the MiMo series, featuring the flagship MiMo-V2-Pro, the multimodal MiMo-V2-Omni, and the MiMo-V2-TTS model. These models are now available via API, with the TTS model currently offered for free.
