## Unify-Agent improves image generation for long-tail concepts via retrieval

Unify-Agent shifts image generation from pure parametric memory to an agentic 'retrieve-then-generate' pipeline. By training on 143K trajectories and using the new FactIP benchmark, the model achieves better accuracy for obscure or long-tail cultural concepts.
