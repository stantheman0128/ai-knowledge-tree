## LoST tokenization shifts 3D generation from geometric to semantic hierarchy

LoST improves 3D autoregressive generation by reordering tokens based on semantic salience rather than geometric hierarchy. This method achieves better reconstruction quality while using only 0.1% of the token count required by prior methods.
