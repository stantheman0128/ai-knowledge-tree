## CoCo uses code generation as a reasoning chain to improve spatial layout in images.

The CoCo model generates executable code to define spatial layouts before rendering images, significantly outperforming natural language chain-of-thought. This approach improves performance on dense text and multi-element scenes by nearly 69%.
