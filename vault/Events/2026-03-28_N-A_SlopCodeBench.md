## Coding agents show significant redundancy and structural decay

A new benchmark, SlopCodeBench, reveals that coding agents produce 2.2x more redundancy than human developers and fail to maintain code quality over multi-turn iterations. The study concludes that prompt engineering is insufficient to solve these architectural planning issues.
