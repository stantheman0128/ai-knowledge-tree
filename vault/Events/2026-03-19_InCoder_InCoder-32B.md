## InCoder-32B foundation model launched for industrial code intelligence

InCoder-32B is a new 32-billion-parameter foundation model specifically designed to unify code intelligence across chip design, GPU kernel optimization, and embedded systems. By training on hardware semantics and resource constraints, the model aims to outperform general-purpose code models in specialized industrial domains.
