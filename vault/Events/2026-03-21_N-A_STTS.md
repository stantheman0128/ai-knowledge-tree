## STTS unifies token pruning across ViT and LLM for efficient video processing

STTS provides an end-to-end trainable framework that prunes tokens in both the Vision Transformer and the LLM simultaneously. This unified approach maintains performance while significantly increasing efficiency, especially for long-form video tasks.
