## LLM2Vec-Gen improves text embeddings by encoding model responses instead of user queries.

LLM2Vec-Gen uses self-supervised distillation to create embeddings based on how an LLM would answer a prompt rather than the prompt itself. This approach improves MTEB performance by 9.3% and enhances safety alignment in the embedding space.
