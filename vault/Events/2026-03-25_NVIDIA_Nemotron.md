## NVIDIA adopts PivotRL for efficient agentic post-training in Nemotron models.

NVIDIA has integrated PivotRL into its production pipeline for Nemotron models, using local reinforcement learning on SFT trajectories to improve performance. This method achieves near end-to-end RL results at a fraction of the compute cost by focusing on high-variance pivot steps.
